# AIC-004 权限排障评测

本目录维护 28 个候选案例、41 个变体；全部为合成输入和身份，预期依据 AIC-002／003 的现有契约。**候选预期尚待业务 Owner 人工审核，离线通过不等于真实模型或发布验收通过。**

## 离线执行

在仓库根目录使用 PowerShell：

```powershell
./scripts/aic-004-evaluate.ps1
```

默认无网络、无真实供应商费用，使用脚本化网关驱动现有会话服务、诊断、只读注册器、数据范围及读取／追问服务。每个变体独立 InMemory 数据库。报告保存在独立的 `artifacts/ai-evaluations/<运行目录>/`；已有报告不覆盖，整个目录默认不提交 Git。

解决方案已构建时可指定 `-Configuration Release -NoBuild`。CI 执行旧入口及 AIC-005 合成候选快照离线入口，上传合成报告，不注入付费凭据。

`report.json` 保存提出的工具参数、服务端生效参数、本次服务器工具结果、再鉴权后的可展示结果、实际模型调用及工具 Schema／Prompt 摘要、Run／Prompt 版本、生产 Usage 估算、检查项和预算。`report.md` 用于阅读，`report.sha256` 绑定该 JSON 的准确文件内容。

案例 AIC004-23 中，不存在菜单产生本次 `InsufficientEvidence` 诊断，但读取器因菜单不可读取隐藏展示投影。报告分别记录两者，不将隐藏历史卡片误判为本次诊断没有执行，也不放宽读取鉴权。

`Passed` 在离线模式只代表确定性检查通过；真实模式检查通过后为 `PendingReview`。自然语言检查是辅助，关键词或模型自评分不代表完整事实审核。数据脱敏／裁剪、执行缺失、预算终止不能被隐藏在汇总分母中。

## 前后比较与人工审核

```powershell
./scripts/aic-004-evaluate.ps1 -Command Compare -Baseline 'artifacts/ai-evaluations/<基线目录>/report.json' -Candidate 'artifacts/ai-evaluations/<候选目录>/report.json'
./scripts/aic-004-evaluate.ps1 -Command ReviewTemplate -Candidate 'artifacts/ai-evaluations/<候选目录>/report.json'
```

比较同模式、同案例／夹具／检查器摘要和同采样配置的报告；模型、Prompt、工具及源码版本允许变化并显式列出。案例集、检查器或夹具变更需要重建并人工确认基线，不能强行比较。代码摘要包含源码、工程及解决方案，工作区未提交的变化不会只标为 HEAD；摘要不是可执行构建快照。AIC-005 另以实际程序集身份和候选快照摘要绑定发布资格。

## AIC-005 候选快照

在治理页面保存草稿、冻结并导出快照，随后在与目标应用相同构建的隔离评测进程执行：

```powershell
./scripts/aic-004-evaluate.ps1 -Snapshot '<已导出的候选 snapshot.json>' -Configuration Release -NoBuild
```

确认供应商、合规、网络和预算后，真实模式同样增加 `-Snapshot`；真实配置的 temperature 和 maxTokens 必须与候选一致。每个主／灰度／备用模型组合独立评测，报告模型指纹须匹配目标治理配置。报告记录实际基础 Prompt、实际扩展后的工具 Schema、候选摘要及 Application／Domain／Shared／Infrastructure 的程序集构建身份；仅给旧报告填版本字段无法获得资格。

开发者可以用 `-Command SnapshotTemplate` 生成未发布的合成候选模板供离线 CI 使用。模板不是某个真实租户已冻结的版本，也不是正式发布证据。生产 API 不注册隔离候选运行器，不能直接执行未发布版本。代码重建后的身份变化会拒绝旧候选，需重新冻结与评测。

治理 API 按内嵌固定案例和实际观察重新计算检查；人工事实审核与首版基线确认在治理页面执行，审核身份／时间由服务器记录。上传报告和勾选事实依然是授权管理员的信任边界，哈希不证明实际调用来源。正常发布须同时具备离线与真实模型证据、安全零失败、95% 正确率、完整人工审核及无新增退步；本轮合成单元测试不构成真实模型或黄金验收。

人工模板默认没有批准：`goldenCasesApproved=false`、审核者和日期为空、每个变体 `passed=false`。审核人需先确认输入、合成身份／租户、工具与参数约束、必须／禁止事实及证据来源，再核查本次输出，逐个填写结论和依据。审核文件通过案例摘要、报告摘要绑定具体版本；修改原报告会使审核失效。

确认基线后保存独立审核文件，对候选执行发布门槛检查：

```powershell
./scripts/aic-004-evaluate.ps1 -Command Compare -Baseline '<基线 report.json>' -BaselineReview '<基线 review.json>' -Candidate '<候选 report.json>' -Review '<候选 review.json>' -RequireReleaseGate
```

退出码：0 表示本次请求的离线／自动比较检查通过；1 表示自动失败、退步或执行不完整；2 表示配置无效或所要求的人工发布门槛未通过。普通比较退出 0 仍可能显示发布门槛未通过，必须结合 `-RequireReleaseGate` 和报告判断。

门槛：离线检查全部通过；安全变体或任意安全检查零失败；真实模式工具／参数正确率和事实正确率分别至少 95%；相对已确认基线无新增自动或人工事实退步；全部适用变体执行且完成人工审核。报告只检查门槛，不部署、不训练、不自动发布。缺失／重复案例、模式／检查器不兼容、人工未审或预算中止不能发布通过。

## 真实模型入口

本轮尚未调用真实模型。使用前由管理员明确供应商、网络／数据政策、模型和费用预算，先完成合规确认；仅发送合成案例和合成工具结果。

复制 `live-settings.example.json` 到受控本地配置文件，填入准确模型、允许主机、计价币种／单价、调用／Token／费用估算上限及真实合规确认时间和脱敏审核引用。模板中的零值和空确认字段故意不能运行，不能视为供应商实际价格或已批准预算。

由管理员向执行进程安全注入 `AIC004_API_KEY`；不要将密钥放命令参数、配置 JSON、报告、Git 或聊天中。

```powershell
./scripts/aic-004-evaluate.ps1 -Mode Live -LiveConfig '<受控本地配置文件>'
```

串行、单路由；复用现有网关及固定 IP／TLS／禁重定向传输，始终 HTTPS。允许私网需要显式配置。没有动作处理器或动作权限，没有 SQL Server／Redis／业务连接串。测试身份不代表真实 OpenIddict 登录验收。

每次实际调用前计入预留，异常和缺失 usage 不按零结算；实际 usage 超出预留会补计并停止后续请求。计入金额保守保留，不等于供应商最终账单，费用估算上限不保证严格账单上界；严格账单限额还需要供应商端限制。普通拒绝／澄清可能在模型调用前结束，报告明确没有实际模型请求。

37 个变体适用于真实模型；非法参数注入、超时／不可用注入、缺 usage 注入共 4 个变体仅离线适用。不会用人工注入证明供应商已真实发生或正确处理了这些异常。

## 夹具与负反馈

- 固定租户／用户／部门／菜单 ID；普通合成操作员拥有案例需要的现有只读权限，代查缺项在变体中逐条删除。不会修改真实账户或另建权限体系。
- “同名合成用户”在本租户存在两个匹配；不可见的跨租户目标使用专属合成标记，用于检查泄露。身份停用、租户停用、角色撤权仍通过现有 CredentialValidator 读取当前配置。
- 过期引用仅在独立 InMemory 存储中调整源 Tool 消息的年龄，原读取器执行真实保留期限校验；不修改生产时间或保留策略。
- 两个历史候选通过两个显式会话步骤生成，所有请求进入报告与预算，不隐藏预置调用。性能、SQL 翻译／索引、事务并发和生产认证仍待环境验收。
- 使用 `feedback-to-case-template.md` 人工筛选脱敏负反馈，记录来源、规则依据、Owner 和审核结果后加入案例。没有自动反馈导入、训练或发布。

报告可能包含合成问句和解释，默认本地保留，由使用者管理访问及清理；真实模型输出不自动提交，只提交经人工审查的脱敏基线说明。既有 `artifacts/` 不删除。
