## 2. 首批范围与边界 [Architect]

首批实现三个版本化结果类型，限四个已存在的只读工具：

| 结果类型 v1 | 工具 | 可连续追问的参数 |
| --- | --- | --- |

| `table` | `permission.users.search` | 关键词、启用状态、展示上限、当前部门附加过滤 |

每个结果携带服务端生成的 Run／Invocation 引用、结果与工具版本、查询时间、评估口径、实际生效条件、来源引用、限制和截断标志。工具决定列、指标和来源，模型不能提交这些展示定义。

表格的 `totalCount` 为权限范围内匹配记录总数，`displayedRowCount` 为实际展示数。统计的匹配日志总量与分组条数分别表达；操作模块分组显示总分组数、展示分组数和是否截断，不能将前 20 个模块当作全部模块。权限结果仍使用 AIC-002 的服务端结论与证据，不把“检查项数量”表述为用户或业务记录总量。

本次保持部门／角色查询、批准报表、Demo 草稿的既有行为。受控指标、报表数据范围开放、外部 MCP 接口扩展、后台执行、版本发布及自动评测属于后续任务。尤其保留报表工具的全部数据范围要求。

## 3. 结果和上下文设计 [Architect]

### 3.1 服务端结果封套

在 Application/AiCenter 增加类型明确的结构化结果 DTO 和读取器。采用版本化封套保存裁剪后的结果数据、规范化查询上下文及来源元数据，沿用既有 `AiMessage` 的 Tool 消息；不同时存一份旧原始结果和一份完整新结果。

封套必须由会话服务对首批白名单工具生成。持久化时关联真实成功调用，记录实际参数及结果摘要；读取时核对消息角色、`ModelGenerated=false`、内容摘要、封套／工具支持版本、租户、所有者、会话、Run、Invocation、调用状态和对应输出摘要。上下文与结果均需覆盖完整性检查，不只校验 Data 部分。

会话详情和 Run 响应增加可选 `structuredResults`，保留原 `permissionDiagnostics` 兼容投影。聊天组件优先渲染新结果；同一 Run／Invocation 的旧诊断投影不重复展示。旧 v1 权限封套通过现有读取器校验后适配；其他旧 Tool JSON 缺少实际条件，继续纯文本兼容，不从助手文字或摘要反推参数。

### 3.2 最小结构化上下文

上下文包含版本、工具类型／版本、源 Run／Invocation 引用、明确的业务对象引用、允许修改的字段以及实际生效参数。日志上下文保存绝对起止时间，不保存“最近七天”等已失去锚点的文字。默认自查保留 self 语义，执行时由服务端解析；不得用历史身份代替当前身份。

不保存角色、权限集合、超级管理员标记、Token、会话凭据、原始日志、任意 SQL、模型生成的解释或路由 URL。允许修改字段由服务端按工具固定定义，不能信任持久化数据或模型提供的任意字段清单。

`SendAiMessageRequest` 可携带可选 `contextRef`（RunId／InvocationId），前端通过结果卡片选择追问对象。它只是定位提示，后端必须限定为本人当前租户、当前会话中的有效结果。旧客户端只传 Content 仍可使用；未选择对象时，仅在存在一个合法候选且工具类型明确时使用，否则要求澄清，不能猜选最后一条结果。

已有工具函数增加可选上下文引用；仍使用原函数完成对应业务查询，不新增混合业务的通用查询工具。编排层解析和鉴权上下文，合并白名单参数补丁，再调用现有注册器和处理器。外部 MCP 不提供会话上下文解析能力，也不因内部追问获得新授权。

### 3.3 连续追问与参数校验

- 未出现的参数继承实际历史值；出现的参数只替换该字段；仅支持清除的可选过滤接受 null 清除。非法字段、错类型、空 GUID、超长值、超限行数及非法组合直接拒绝。
- 已选择引用后，工具和引用必须对应；引用失效或不可读时不能回退成不带原过滤的新查询。修改诊断类型时按新类型校验必要字段，不能携带旧类型的不适用资源参数。
- “只看本部门”只作用于用户表格：增加受控部门模式，服务端读取调用者最新有效部门；现有数据范围与该部门条件取交集。本部门仅指当前部门，不含下级。无部门或部门已不可用时明确返回无法应用该过滤，不能退化为全部部门。
- 调用者部门／超级管理员状态过期、身份或租户停用时拒绝继续，沿用 AIC-002 最新认证状态检查及共用范围计算。历史上下文不保存已授权部门清单。
- 日志保留现有用户名／模块包含匹配、默认最近七天、时间闭区间和最长 31 天限制；传给上下文的是归一化后实际值。不会默改既有统计口径。
- 代码没有业务时区配置。“上个月”必须先明确时区或 UTC 偏移；缺失时请求澄清，不能依据浏览器、执行宿主或模型猜测。明确后以当次服务端时间为锚，计算上个自然月的绝对边界，并显示时区、起止值和闭区间口径；测试覆盖月末、跨年及不同偏移。
- 名称只能用于已授权搜索；多个匹配、截断导致不能证明唯一、目标删除或不可读时，不凭助手文字确定对象 ID。明确 ID 仍需逐次检查存在性和可见性。

新模型请求使用受限用户对话和经校验的最小查询上下文；历史助手文字、旧工具结果正文和用户／模块名称不作为授权、事实或默认参数来源。结构化上下文作为数据传入，不拼入系统指令；历史行内容中的指令文本不能修改工具、租户、身份或允许字段。当前事实必须来自本次重新执行的工具。

### 3.4 逐次授权与历史展示

每次执行重新检查功能开关、允许租户、当前有效身份、工具完整权限集及业务范围。继续复用 OpenIddict、`IUserCredentialValidator`、既有权限计算和数据过滤，不建立平行权限体系。

读取历史结果同样重新鉴权：权限证据沿用 AIC-002 的 `CanReadAsync`；日志摘要检查当前完整工具权限；用户表格检查当前范围内每个已展示用户的可读性。用户删除／越出范围或当前范围缩小导致不能安全展示原查询范围时隐藏原卡片并提示重新查询，不把裁剪后的历史行与原总量误称为当前结果。

结果标注历史查询时间，重载只读取历史快照，不自动执行工具或产生供应商费用。选中历史卡片再追问才发起新查询。既有助手纯文本的历史读取策略保持兼容，撤权不能追溯消除用户已看到或保存的内容；该限制必须写入验收记录。

### 3.5 前端

新增结构化结果分发组件，复用 `AiPermissionDiagnosticCard.vue`，增加固定列用户表格和统计摘要组件。按 Run／Invocation 关联结果，展示口径、条件、查询时间、总量、展示数量、截断和来源，并显示当前选择的追问对象，切换／删除会话时清除选择。

未知版本显示明确的不支持提示，缺失结构化结果的旧会话继续纯文本展示。所有用户输入和结果字段按文本转义。建议入口复用固定标识、受控路由白名单、当前前端权限及路由注册检查；不渲染模型／结果提供的任意 URL，不新增直接修改权限的动作。

## 4. 数据评审 [DBA]

结论：**无数据库结构变更、无新增 EF 迁移、无权限种子变更**。保留现有实体、租户、审计及软删除机制。

已实现上限：每个结构化封套 UTF-8 序列化最多 64 KiB，其中上下文最多 4 KiB；单次结构化读取最多 256 KiB。用户行数继续受现有 `MaxToolRows` 控制，模块展示最多 20 组，权限证据继续遵守既有 20 项和 16,384 字符限制。诊断沿用既有证据裁剪；统一封套按序减少表格行／统计分组并明确标记截断。如果必需元数据和最小上下文仍超限，返回受控错误，不静默丢失过滤条件。

结果和上下文沿用 `ConversationRetentionDays`（默认 30 天）；读取和执行均按源消息 CreatedAt 主动检查保留期限，过期不可复用，即使清理任务尚未运行。不得复制到保留时间更长的 CitationJson、日志或新表；引用审计仅保存现有来源及摘要。

读取按当前租户、会话、Run 和时间范围过滤；最近结果窗口为 50 条消息，成功调用候选最多 501 条，超限明确返回窗口限制。指定 Run 可读取保留期内较旧结果。用户可见性检查批量查询，避免逐行认证／范围重算。实际 SQL Server 查询计划仍待环境验收；如确需索引／映射变更，返回 DBA 重新评审，不默认加迁移。

应用回退后新封套仍是隐藏的 Tool 消息；旧客户端保留纯文本和兼容诊断字段，无需回填、Down 或删除数据。模型调用预算、取消、超时、调用审计和引用链路保持既有机制。

## 7. 已确认范围与实现补充

用户已确认首批三类结果、四个工具、现有消息存储方案及大小／保留限制，以及本部门仅含当前部门、相对月份缺时区时先澄清的行为。确认不包含实际数据库操作、生产发布或 commit／push。

- Agent／Prompt 版本为 2.2。用户原始消息保持纯文本；引用、明确 UTC 偏移和请求消息 ID 独立存为同 Run 的最小 Tool 元数据，自动解析引用后更新原元数据。重试校验其摘要、归属和保留期限，不可用时拒绝退化为新查询。
- 两个精确示例“只看本部门”“再看上个月”由服务端约束仅改变预期条件。缺引用、对象歧义或缺时区时返回非模型澄清消息，不执行查询。
- 前端自然月 UTC 偏移需用户明确选择，无默认值；当前选择器覆盖 UTC−12 到 UTC+14 的整小时，API 支持分钟偏移。结果保存并显示实际绝对起止值及闭区间口径。
- 完整结果封套及其上下文共同纳入消息与调用输出摘要校验。用户表格读取检查当前数据范围指纹和批量行可见性；删除菜单后隐藏原菜单证据。
- 内部 `StructuredResult` 标为 JsonIgnore，不作为外部 MCP 输出字段；外部 MCP 不支持会话引用、部门过滤或相对月份参数。
