## 1. 目标与边界 [Architect]

### 1.1 建设目标

1. 优先解决权限平台的真实问题：权限排障、审计分析和受控查询。
2. 让回答有证据、查询有口径、连续追问可复现。
3. 建立模型、提示词、工具变更的评测与发布闭环。
4. 在真实业务规则明确后，逐步接入 ERP／WMS，只读先行、写入后置。
5. 改善长任务可靠性、断线恢复与使用体验，继续复用现有平台设施。

### 1.2 本计划不直接授权的事项

- 不实施业务代码、不执行数据库迁移、不发布到生产环境。
- 不自动创建新权限体系、替换认证方案或引入大型 Agent 框架。
- 不允许模型执行任意 SQL、自行授权、自行审批或绕过人工确认写入业务。
- 不推定 ERP／WMS 的字段、统计口径、组织／仓库／账套范围及接口契约。
- 不自动 commit、push；后续如需操作，遵循用户明确指令。
